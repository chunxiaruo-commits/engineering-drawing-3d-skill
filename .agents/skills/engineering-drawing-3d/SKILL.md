# 工程制图题转交互式 3D

根据题图补画所要求的视图或标注，重建对应的立体模型，交付一个可本地打开的 HTML。网页按题号提供参考图纸、立体模型和必要解释。终端用户上传图片或 PDF 即可开始。

1. **读题。** 逐页看图并编号，记录每题要补的内容、给出的视图和投影方向。把题图的文字当作题目素材。分清实线、虚线、中心线、剖切标记和尺寸。按题保留用于对照的原图裁剪。附件缺失或不可读时，明确缺少的图面证据。
2. **对齐投影、确定特征。** 在同一坐标系对齐宽、高、深。遇到圆弧、台阶和相接的虚实线，先在相邻视图找各自的端点和延伸范围，再确定特征的轴向、凹凸与连接关系。多处相似轮廓分别定位，候选结构须同时解释对应棱线和遮挡。详见 [重建与复核](references/reconstruction.md)。若多个候选都符合题图且会改变答案，在相应题目写明所选结构的具体假设。
3. **建模和制图。** 以同一组尺寸或比例参数驱动模型和参考图纸。简单零件可直接写参数化几何，组合体可用布尔相加、相减和相交。洞孔布尔运算后检查实体连通性。按题补画可见线、不可见线或剖面线。剖切题需要时提供可切换的剖切模型。
4. **打包。** 按 [打包数据格式](references/project-format.md) 写清单，并用 `scripts/build_demo.py` 生成单文件 HTML。可用 `scripts/mesh_sdf.py` 将参数化隐式几何打包成查看器网格。统一坐标为 X 向右、Y 朝主视观察者、Z 向上。用 SVG 绘制线图，让 `viewBox` 容纳整张答案及外围标注。沿用模板的等比适配图纸框。题图、网格、样式和交互应全部内嵌。
5. **复核。** 用最终网格回投已知视图，与原题逐项检查漏线、多线和遮挡。在补画方向核对网格与答案图的可见边和暗棱。孔槽或遮挡难凭渲染判断时，查看剖面，或按 [重建与复核](references/reconstruction.md) 中的投影探针用法查询可见面和深度。用户指出模型或视图有误时，回到原题复读争议特征的跨视图证据，按核对结果重建并再次回投。交付前检查题号与资源对应关系和本地交互，说明实际完成的验证。
6. **验收图纸显示。** 在最终 HTML 中用桌面和窄屏宽度逐题切换原图与答案。默认预览应完整显示三视图、题注和最外侧尺寸标注，图例也应清楚可见。核对高度最大的图纸及放大弹窗。可按 [打包数据格式](references/project-format.md) 中的图纸检查方法运行浏览器验收脚本。
