# 重建与复核

## 从题图提取参数

- 抄下当前题号和作图目标。尺寸标注题保留题设的取值方式。剖视题记录剖切位置和箭头方向。
- 以视图名称、投影法符号和投影线为准。第一角法的常见排布把俯视图放在主视图下方、左视图放在右方。第三角法的常见排布相反。照片经过裁剪或旋转时先恢复原排布。
- 主视与俯视共宽，主视与侧视共高，俯视与侧视共深。同一特征至少核对相邻视图中的中心、起止线和可见性。
- 优先读取标注尺寸。无标注时先找可用比例与基准。照片未校正、截图缩放未知，或者仅能读到长度比时，使用相对单位。要按 1:1 量取时，记录采用的原卷或 PDF 物理尺寸及取整规则。

## 从特征证据确定结构

| 题图线索 | 还需要确定的内容 |
| --- | --- |
| 主视图的圆 | 凸台、凹孔或通孔。查相邻视图的虚实线、深度和端点。 |
| 两条平行虚线中断 | 检查中断处是否与窗槽或另一孔相交，或到达盲孔终点。 |
| 在不同视图中看到相似的圆弧 | 各自用宽度或高度定位圆弧端点，再找相邻视图对应的轴向边与终止面。比较哪一侧伸出、哪一侧切入，以及各自覆盖的深度和高度。 |
| 同一位置的一条线从实线转为虚线 | 放大原图确认线型。追踪同一棱的完整范围，找出在该观察方向上遮住虚线段的具体表面。 |
| 两个视图外轮廓都吻合 | 再核对凹槽底、孔壁、交线和被遮挡边。外轮廓可能支持多个模型。 |
| 一个视向出现剖切标记 | 按箭头确定视线，画被切到的材料与后方可见轮廓。沿肋纵剖时按题目采用的制图惯例处理剖面线。 |

例如，主视的两条同心半圆可能对应后部横槽与悬伸凸缘。把弧的端点转到俯视，内、外圆柱的直边可从不同位置起始，并在凸缘端面终止。俯视前缘的另一组半圆可通过主视下部两对竖线定位到前端、不同高度的两层槽壁。此时两个结构的轴向和位置都有各自的投影依据。检查凸缘根部被遮挡的棱，以及前端台肩在侧视中是否被侧壁盖住。

**信息不足时**，用能区分候选的特征做比较，例如台肩是凸是凹、孔在哪个面终止、某一段之后是否仍有材料。若用尽现有视图后仍有多个候选成立，在网页写出会影响答案的几何假设，交付对应的参考解。用户指出错误时，先逐条重读争议区域的原始线型和端点，再判断需要改几何、投影，还是绘图参数。

## 对最终网格复核

1. 核对主视、俯视、侧视的朝向和对齐关系。
2. 用交付网格在已知方向做正投影。以原图为基准对齐比例、中心和基线。先从原图找模型漏掉的边，再从投影找原图空白处多出的边。中心线和尺寸线单独对齐。虚线可用该棱的投影位置和前方遮挡面核对。
3. 从补画方向核对答案与网格的可见边、被遮挡边。可用剖面或从关键位置取射线，查圆弧极值、台阶两侧、开口和预期留空处。若已知视图吻合但补画线型不符，查观察方向与遮挡；若模型也解释不了原图，重审几何假设。对剖视核对切面材料、空腔和切后可见轮廓。
4. 检查每题的原图、答案和模型对应关系。在能访问的本地浏览器中试题号切换、旋转、平移、缩放、复位、正投影和可用的剖切状态。

### 查询沿视线的表面

用 `scripts/probe_projection.py`（需要 NumPy）从 `.mesh.gz` 或最终 HTML 的内嵌网格读取射线命中。输入点用模型坐标。主视输入 X、Z 并按 Y 从大到小返回，俯视输入 X、Y 并按 Z 从大到小返回，左视输入 Y、Z 并按 X 从小到大返回。

~~~sh
python .agents/skills/engineering-drawing-3d/scripts/probe_projection.py demo.html front --model q1 --bounds -40 40 0 48 0 34 --point 0 11 --point 0 18
~~~

上例检查自制示例的通孔中心和孔上方的实体。第一个命中是最近的表面，空列表表示该处没有命中。用预计被遮挡的棱深度和第一个命中比较，可以辅助判断实线或虚线。恰好沿着面或切边的射线存在退化，需在边两侧稍加偏移再检查。用 `--bounds` 指定网格打包前的轴向范围，省略时使用以包围盒中心为原点的归一化坐标。这个工具用于抽查，完整的线图核对仍以上述回投流程为准。
